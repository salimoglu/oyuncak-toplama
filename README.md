# Oyuncak Toplama

5 yaşındaki çocuklarla birlikte oynanacak, dağınık odalardaki oyuncakları karakterlerle toplayan basit bir web oyunu. Tablet ve bilgisayar tarayıcısında çalışır.

## Nasıl oynanır?

1. **Oyna** düğmesine bas.
2. Bir **karakter** seç (Elif, Can, Lila veya kedi Karamel).
3. Dağınık bir **oda** seç (yatak odası, oyun odası, salon, bahçe).
4. Oyuncağa **dokun veya tıkla**. Karakter oraya gider ve oyuncağı kutuya koyar.
5. Oda bitince yıldızlar çıkar; başka odaya geçebilirsiniz.

Zaman sınırı ve kaybetme yok. Amaç birlikte toplamak.

## Oyunu açmak

- Bilgisayarda `index.html` dosyasını tarayıcıda açın.
- Tablette aynı adresi tarayıcıdan açın; ana ekrana eklerseniz uygulama gibi açılır.

Yayınlanmış hali GitHub Pages üzerinde olur:

`https://<kullanıcı-adın>.github.io/oyuncak-toplama/`

## Geliştirme

Bu bir statik sitedir: HTML, CSS ve JavaScript. Kurulum veya derleme gerekmez.
